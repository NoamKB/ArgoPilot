מילון קצר

מונחמה זה, במשפט אחד
idempotentאפשר להריץ שוב ושוב ומקבלים אותה תוצאה. שרת חדש ושרת שנפרס 20 פעם מגיעים לאותו מצב.
systemd / unit"מנהל המשמרות" של Linux. ה־unit הוא קובץ קטן שאומר לו איך להפעיל שירות ולהחזיר אותו אחרי קריסה או אתחול.
Docker / container / volume"קופסה" שמריצה תוכנה מבודדת (כאן PostgreSQL). ה־volume הוא המקום שבו הנתונים נשמרים מחוץ לקופסה, כך שהם שורדים גם אם היא נמחקת.
.env מול .env.example‏.env.example נמצא ב־Git ומראה אילו הגדרות צריך, בלי סודות. .env הוא הקובץ האמיתי שהשירות קורא, ולא נכנס ל־Git.
uv / uv sync --lockeduv מתקין ספריות Python. --locked: בדיוק לפי uv.lock, ונכשל במקום לעדכן בשקט.
uvicornהתוכנה שמריצה שירות Python (FastAPI) ומקשיבה על פורט.
npm / npm ciהמקבילה של uv בעולם JavaScript. npm ci מתקין בדיוק לפי package-lock.json.
curlשולח בקשת HTTP מהטרמינל, כמו דפדפן בלי מסך. בעזרתו בודקים "אתה חי?".
health checkבקשה קצרה לשירות. תשובת ok אומרת שהוא עלה ועונה.
Secretערך ש־GitHub שומר מוצפן. אי אפשר לקרוא אותו בחזרה, ובלוגים הוא מוצג כ־***.
runnerמחשב זמני של GitHub שמריץ את ה־workflow ומתחבר לשרת ב־SSH.
fingerprint"תעודת זהות" של השרת. ה־workflow בודק אותה כדי לא להתחבר למתחזה.
port, 127.0.0.1 מול 0.0.0.0פורט הוא "מספר דירה" בשרת. 127.0.0.1: רק מתוך השרת. 0.0.0.0: גם מהאינטרנט.
